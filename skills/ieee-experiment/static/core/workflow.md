# Workflow

1. Extract all explicit claims from title, abstract, introduction, method, and conclusion.
2. Convert each claim into required evidence.
3. Inventory current evidence: datasets, baselines, metrics, ablations, robustness tests, complexity, and implementation details.
4. Find gaps between required evidence and current evidence.
5. Classify each gap by review risk: Critical, Major, or Minor.
6. Recommend the smallest set of experiments that closes the highest-risk gaps.
7. For result writing, phrase only the claims supported by available evidence.

Keep the audit claim-centered. Avoid generic experiment wish lists.
