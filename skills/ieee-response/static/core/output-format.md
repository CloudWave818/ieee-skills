# Output Format

For multiple comments:

```text
Revision action list
1. ...

Point-by-point response
Reviewer comment:
Classification:
Response:
Manuscript revision:
Evidence:
```

For one comment:

```text
Reviewer comment:

Classification:
- comment_type:
- action_type:
- evidence_status:

Response:

Manuscript revision:

Evidence:
```

Keep the response concise unless the reviewer asks for detailed technical justification.
