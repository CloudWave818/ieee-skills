# Workflow

1. Identify task, source type, citation role, and verification level.
2. Check whether the citation supports the local sentence or paragraph claim.
3. Check metadata completeness.
4. Check IEEE style or BibTeX structure.
5. Flag missing classic, baseline, or recent work when visible from context.
6. Verify metadata only when allowed or required.
7. Return fixes with verification status.

Do not invent missing metadata.
