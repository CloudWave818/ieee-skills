# LaTeX Placement Stage

Check whether the figure/table should be one-column or two-column.

Use IEEEtran-compatible float logic:

1. `figure` or `table` for one-column objects.
2. `figure*` or `table*` only for necessary two-column objects.
3. keep captions near objects.
4. avoid manual placement hacks unless necessary.

Read `../_shared/references/ieee-latex-guidelines.md` for deeper LaTeX work.
