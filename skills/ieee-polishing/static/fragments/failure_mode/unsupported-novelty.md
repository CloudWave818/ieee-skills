# Unsupported Novelty

Do not leave "novel" unsupported. Tie novelty to a concrete distinction:

1. architecture,
2. objective function,
3. control law,
4. signal representation,
5. deployment constraint,
6. condition-specific robustness.

If the closest prior work is not stated, replace novelty language with conservative wording such as "we propose" and add a note asking for prior-work contrast.
