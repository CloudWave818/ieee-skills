# Failure Modes

Look for these common IEEE manuscript problems:

1. Vague claims: "good performance", "obvious improvement", "important significance".
2. Unsupported novelty: "novel" without comparison to close prior work.
3. Weak contribution: contribution describes implementation rather than technical advance.
4. Poor method rationale: algorithm selection is not linked to system features.
5. Chinglish logic: sentence order mirrors Chinese exposition and buries the engineering cause.
6. Result underreporting: the text says experiments prove effectiveness but omits dataset, baseline, metric, or value.
7. AI-like prose: formulaic transitions, generic certainty, symmetrical sentence rhythm, and broad claims that are not anchored to the author's actual method, setup, or observed results.

Repair language only after diagnosing the failure mode.
