# Workflow

1. Split reviewer/editor text into separate comments.
2. Classify each comment by `comment_type`.
3. Decide the required `action_type`.
4. Determine whether evidence is added, planned, unavailable, or text-only.
5. Draft the manuscript revision action before drafting the response.
6. Write the response with thanks, action, evidence, and location.
7. Use placeholders for unknown page, line, section, table, figure, or result values.
8. Build a revision action list for multi-comment responses.

Do not answer a technical criticism with wording changes alone when evidence is required.
