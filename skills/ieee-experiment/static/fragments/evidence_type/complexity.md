# Complexity Evidence

Use when the manuscript claims lightweight, real-time, deployable, low-cost, or efficient design.

Report appropriate evidence:

1. parameters,
2. FLOPs or MACs,
3. latency,
4. memory,
5. power,
6. throughput,
7. asymptotic complexity,
8. platform and implementation details.

Complexity claims without hardware/platform context are often weak.
