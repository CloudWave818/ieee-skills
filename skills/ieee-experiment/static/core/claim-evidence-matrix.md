# Claim-Evidence Matrix

Use this table whenever the user asks whether experiments are sufficient:

```text
Claim | Required evidence | Current evidence | Missing experiment | Review risk
```

Claim examples:

1. "The method improves accuracy under variable-speed conditions."
2. "The module contributes to robustness."
3. "The model is lightweight enough for deployment."
4. "The controller remains stable under disturbance."

Required evidence should be specific, not generic:

```text
cross-speed test against classical and recent baselines using macro-F1
```

not:

```text
more experiments
```
