# Chinglish

Common repair moves:

1. Put the technical subject before the evaluation.
2. Replace "there is" and "it has" openings with concrete subjects.
3. Split long cause-result chains.
4. Avoid translating "certain", "obvious", "relatively", and "good" literally.
5. Convert "in order to" to a more direct method-purpose relation when possible.

Keep terminology stable across the paragraph.
