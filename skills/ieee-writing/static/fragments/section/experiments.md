# Experiments Fragment

The experiment section should prove claims, not merely report scores.

Include:

1. dataset, platform, split, implementation, and settings,
2. traditional and recent baselines,
3. metrics aligned with the task,
4. ablations for claimed modules,
5. condition-specific tests matching the title or abstract,
6. complexity/runtime analysis if efficiency or deployment is claimed.

When drafting results, explain why the improvement matters in engineering terms.
