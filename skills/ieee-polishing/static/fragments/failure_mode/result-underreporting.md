# Result Underreporting

If a sentence claims experimental proof, require:

1. dataset or scenario,
2. baseline,
3. metric,
4. numerical result,
5. condition under which the result holds.

Weak:

```text
Experimental results verify the effectiveness of the method.
```

Better:

```text
On [dataset], the proposed method improves [metric] by [value] over [baseline] under [condition].
```
