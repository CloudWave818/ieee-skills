# Classification

Evidence expectations:

1. accuracy plus class-sensitive metrics such as F1, precision, recall, or confusion matrix when imbalance matters.
2. clear train/validation/test split.
3. leakage prevention.
4. traditional and recent baselines.
5. ablation for each claimed module.
6. repeated runs or variance when stochastic training affects results.

If robustness is claimed, test noise, domain shift, class imbalance, or operating-condition changes.
