# IEEE AI Writing and Review Risk

Use this reference when a user asks about AI-like writing, AI-rate concerns, suspected AI-generated reviewer comments, or unfair generic review feedback.

## Writing Risk

Do:

1. make the text source-grounded: object, condition, method, metric, baseline, dataset, and result should be visible where relevant;
2. preserve the author's actual technical decisions and limitations;
3. remove generic praise and replace it with bounded claims;
4. vary structure only to improve logic, not to imitate a style;
5. flag unsupported claims instead of making them smoother.

Do not:

1. claim that text can pass any AI detector;
2. deliberately obfuscate authorship;
3. add fake personal voice, fake lab details, fake mistakes, or unverifiable citations;
4. weaken clear technical writing only because it might be misclassified.

## Review-Comment Quality Audit

Never assert that a reviewer comment was written by AI unless there is direct evidence. Instead, classify observable quality problems:

1. generic criticism with no manuscript-specific evidence;
2. contradiction with the submitted text, figures, or tables;
3. demand for impossible, irrelevant, or out-of-scope experiments;
4. hallucinated method, dataset, citation, equation, figure, or result;
5. internally inconsistent requests;
6. template-like comments that do not identify page, section, claim, baseline, or result;
7. comments that conflate unrelated fields or venues.

## Editor-Facing Escalation

If a review appears careless or unsupported, advise the author to:

1. respond first on substance;
2. quote the exact reviewer statement;
3. cite the manuscript location or evidence that contradicts it;
4. avoid accusing the reviewer of using AI;
5. ask the editor to consider the discrepancy or clarify the request.

Suggested wording:

```text
We respectfully ask the editor to consider that Comment [X] appears inconsistent with the submitted manuscript. Specifically, the comment states [reviewer claim], whereas [Section/Fig./Table] reports [manuscript evidence]. We have nevertheless revised [location] to make this point easier to verify.
```
