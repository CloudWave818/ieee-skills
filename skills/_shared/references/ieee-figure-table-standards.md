# IEEE Figure and Table Standards

Use this reference for IEEE figure, table, and layout checks.

## Figures

Check:

1. Resolution is high enough for print and zoomed PDF reading.
2. Axis labels include units where relevant.
3. Ticks are readable and not crowded.
4. Legends do not cover data.
5. Lines and markers remain distinguishable in grayscale.
6. Fonts are consistent with the manuscript.
7. Captions explain the condition, dataset, metric, and takeaway.
8. Subfigures are labeled consistently.

Axis ranges should not mislead. Bar charts and absolute quantities usually should start from zero. Curves may use nonzero ranges when the goal is to show fine differences, but the caption or axis should make this clear.

## Tables

Check:

1. Units are in headers.
2. Decimal precision is consistent.
3. Best and second-best results are marked consistently.
4. Baseline and proposed method groups are clear.
5. Rows and columns are not overloaded.
6. Table captions state the dataset, condition, and metric.

## Layout

Avoid:

1. Figure or table caption separated from the object by page breaks.
2. Overly small fonts.
3. Low-contrast colors.
4. Single-column figures squeezed into unreadable size.
5. Manual screenshots of plots when vector export is possible.

## Reviewer Impression

Poor figures and tables can create a rejection bias even when the method is good. Flag formatting issues explicitly in pre-submission review.
