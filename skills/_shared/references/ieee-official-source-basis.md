# IEEE Official Source Basis

Use this reference when a skill needs IEEE-author-center grounded rules rather than general academic-writing intuition.

## Peer Review Axes

IEEE Author Center describes journal and conference review around these reviewer/editor questions:

1. Scope: whether the work fits the target publication or conference.
2. Novelty: whether the material is original and distinct from prior work.
3. Validity: whether the study is well designed and executed.
4. Data: whether data are reported, analyzed, and interpreted correctly.
5. Clarity: whether ideas are expressed clearly, concisely, and logically.
6. Compliance: whether ethical and publication requirements are met.
7. Advancement: whether the work significantly contributes to the field.

Use these axes as the highest-level review gate for `ieee-reviewer`.

## Submission Fit

An IEEE journal article can be rejected before peer review if it is outside the journal scope. The target publication's Aims & Scope and Information for Authors should override generic advice.

Treat Transactions, Journals, Letters, Magazines, and Conferences differently:

1. Transactions and Journals usually expect a complete technical study.
2. Letters usually expect a shorter, focused contribution.
3. Conferences often have tighter page limits and may not offer a revision cycle.
4. Magazines usually need broader readability and less dense technical proof.

## Author Tools

IEEE Author Center points authors to tools that can support final checks:

1. IEEE Publication Recommender for venue fit.
2. IEEE Template Selector for publication-specific templates.
3. IEEE LaTeX Analyzer for LaTeX validation.
4. IEEE Reference Preparation Assistant for reference checking.
5. IEEE PDF Checker for IEEE Xplore display checks.

Skills should mention these tools when the user's task reaches final submission, LaTeX, reference, or PDF compliance work.

## Graphics

IEEE graphics guidance emphasizes accurate and clear high-quality graphics. Line graphs should not rely only on color; grayscale readability, line style, marker shape, brightness contrast, and direct data labels can improve accessibility.

IEEE no longer accepts submitted papers that include the Lena image.

## Revision

For revise decisions, IEEE Author Center instructs authors to read the decision letter carefully and include a point-by-point reply addressing each reviewer suggestion.

Use this as the default response structure for `ieee-response` and as a review-readiness check in `ieee-reviewer`.
