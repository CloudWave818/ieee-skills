# Output Format

For prose drafting:

```text
Detected axes: venue_type=..., section=..., language=..., domain=...

[Drafted text]

Author checks:
- [Only include when needed]
```

For outlines:

```text
Detected axes: ...

Section plan
1. Claim:
   Evidence needed:
   Reviewer risk:
```

Keep `Author checks` short. The draft should remain the main output.
