# Output Format

Default:

```text
Detected axes: visual_type=..., check_type=..., failure_mode=..., stage=...

Figure/table audit
Item | Supported claim | First-impression risk | Technical issue | Fix

Priority fixes
1. ...
```

Caption writing:

```text
Revised caption:
[caption]

Missing information:
- ...
```

Redesign:

```text
Current issue -> Redesign action -> Why it improves reviewability
```
