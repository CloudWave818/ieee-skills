# Stance

Treat figures and tables as IEEE engineering evidence. Each item should answer:

1. What claim does it support?
2. What object, condition, dataset, metric, or method variant is shown?
3. Can a reviewer read it after one-column or two-column IEEE scaling?
4. Does it present comparisons and baselines fairly?
5. Does it expose uncertainty, variability, negative results, and complexity when relevant?
6. Does the caption state the takeaway without overstating the result?

Poor visual quality can bias reviewers before they evaluate the method.

Prefer direct engineering clarity over decorative styling. A good IEEE figure usually makes the baseline, operating condition, metric definition, and evidence for the claimed improvement immediately visible.
