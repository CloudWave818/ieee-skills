# Weak Contribution

A strong IEEE contribution statement should include:

1. the technical object,
2. the proposed mechanism,
3. the limitation or condition addressed,
4. the evidence that validates it.

Weak:

```text
The main contribution is that a model is built.
```

Better:

```text
A dual-branch temporal encoder is developed to separate transient and periodic components, improving classification under variable-speed operation.
```
