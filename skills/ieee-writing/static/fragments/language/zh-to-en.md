# Chinese-to-English Fragment

When drafting from Chinese notes, translate the technical logic rather than sentence order.

Common repairs:

1. Replace "具有重要意义" with the concrete engineering harm or benefit.
2. Replace "研究较少" with a prior-method limitation under a condition.
3. Replace "实验验证了有效性" with dataset, baseline, metric, and result if available.
4. Replace "为了提高准确率" with the specific error source or failure mode.

Do not preserve Chinese paragraph order if it weakens IEEE argument flow.
