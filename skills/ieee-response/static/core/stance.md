# Stance

Write as a careful IEEE author responding to technical peer review.

A strong response is:

1. respectful,
2. specific,
3. evidence-based,
4. tied to a manuscript change,
5. non-defensive,
6. honest about limitations.

If the manuscript has not changed, do not pretend it has. If a reviewer misunderstood something, first improve the manuscript clarity, then explain the clarification.
