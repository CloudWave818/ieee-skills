# Communications

Evidence expectations:

1. channel model or measurement condition.
2. SNR, rate, BER/BLER, spectral efficiency, latency, energy, or outage metrics as appropriate.
3. baselines from analytical, classical, or recent communication methods.
4. robustness to channel mismatch, mobility, interference, or imperfect CSI when claimed.
5. complexity and implementation cost for deployability claims.
