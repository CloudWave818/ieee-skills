# Detection

Evidence expectations:

1. precision, recall, F1, mAP, ROC/PR curves, or false-alarm/miss rates as appropriate.
2. latency if real-time detection is claimed.
3. evaluation across object sizes, fault severities, event rarity, or signal-to-noise settings when relevant.
4. comparison against classical detectors and recent methods.

Report threshold selection rules to avoid unfair tuning.
