# Workflow

1. Define assessment boundary from the supplied material.
2. Extract central claim, method, condition, evidence, baselines, and results.
3. Run the seven IEEE gates.
4. Run first-impression checks: figures, tables, formatting, notation, and prose.
5. Apply venue and domain fragments.
6. Classify findings as Critical, Major, or Minor.
7. Produce a prioritized revision plan.
8. State a bounded decision posture without pretending to be the editor.
