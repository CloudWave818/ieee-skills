# Poor Method Rationale

Repair method-rationale paragraphs by linking system properties to algorithm choices.

Pattern:

```text
Because [system/condition feature] causes [specific difficulty], [method component] is introduced to [technical effect].
```

Avoid:

```text
This algorithm is used because it has strong learning ability.
```

Use concrete features: nonstationarity, sparsity, local transients, delay, saturation, multipath, resource limits, noise, imbalance, uncertainty, or domain shift.
