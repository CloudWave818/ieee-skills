# Response Pattern

Default pattern:

```text
We thank the reviewer for this constructive comment. In response, we have [action]. Specifically, [evidence or explanation]. The revised manuscript now [states/shows/reports] this change in [Section/Fig./Table/Page/Lines].
```

Disagreement pattern:

```text
We appreciate the reviewer's concern. We respectfully clarify that [evidence-based clarification]. To avoid ambiguity, we have revised [location] to explicitly state [clarification].
```

Limitation pattern:

```text
We agree that [limitation] is important. We have added a discussion of this limitation in [location] and clarified that the current study focuses on [bounded scope].
```

Use placeholders instead of invented locations.
