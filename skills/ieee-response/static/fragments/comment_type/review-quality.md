# Review Quality Comment

Use when a reviewer comment appears generic, unsupported, contradictory, hallucinated, or careless.

Response strategy:

1. Address any valid technical concern first.
2. Quote or paraphrase the exact problematic claim.
3. Point to manuscript evidence that contradicts or already answers it.
4. Revise the manuscript to make the evidence easier to find when possible.
5. If escalation is needed, ask the editor to consider the discrepancy rather than accusing the reviewer.

Avoid:

1. "This review was written by AI."
2. "The reviewer did not read the paper."
3. "The comment is meaningless."

Safer wording:

```text
We respectfully note a possible inconsistency in this comment. The comment states [X], while the submitted manuscript reports [Y] in [Section/Fig./Table]. To make this point clearer, we have revised [location] to explicitly state [clarification].
```
