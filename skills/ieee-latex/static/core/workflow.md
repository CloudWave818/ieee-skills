# Workflow

1. Identify template, class options, compiler, and target venue if available.
2. Inspect error log, source snippet, and rendered PDF/page when available.
3. Classify the object and failure mode.
4. Apply a minimal fix.
5. Recompile or recommend the exact compile/check sequence.
6. Check labels, citations, floats, overfull boxes, and visual readability.

When a PDF can be inspected, never decide layout quality from source alone.
