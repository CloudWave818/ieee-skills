Engineering Evidence Chain

IEEE-style papers should make the technical problem, constraint, method rationale, and evidence easy to inspect.

ObjectWhat system or task?
ConditionWhat constraint or scenario?
HarmWhy does it matter?
LimitationWhere do prior methods fail?
RationaleWhy this method?
EvidenceWhich results prove it?

Skills

ieee-writingDraft IEEE-style titles, abstracts, introductions, methods, experiments, conclusions, and contribution statements.
ieee-polishingPolish or translate technical prose into precise IEEE-style academic English.
ieee-reviewerAssess manuscripts with IEEE-style gates: scope, novelty, validity, data, clarity, compliance, and advancement.
ieee-experimentAudit claim-evidence alignment, baselines, ablations, robustness, complexity, and reproducibility.
ieee-figure-tableCheck figure and table readability, captions, accessibility, layout, and first-impression risks.
ieee-responseDraft point-by-point responses, rebuttals, revision plans, and cover letters.
ieee-latexFix IEEEtran LaTeX, floats, equations, algorithms, tables, BibTeX, and PDF checks.
ieee-citationCheck BibTeX, reference metadata, IEEE format, DOI fields, and citation logic.
ieee-paper-readerExtract contributions, methods, equations, experiments, limitations, reproducibility details, and citation positioning.

Quick Start

Goal Skill Prompt
Draft a section ieee-writing Use $ieee-writing to draft an IEEE-style introduction from my problem statement and contributions.
Polish English ieee-polishing Use $ieee-polishing to polish this abstract into concise IEEE-style technical English.
Pre-review a manuscript ieee-reviewer Use $ieee-reviewer to evaluate this manuscript like an IEEE Transactions reviewer.
Audit experiments ieee-experiment Use $ieee-experiment to build a claim-evidence matrix and tell me which experiments are missing.

Install

git clone https://github.com/CloudWave818/ieee-skills.git
cd ieee-skills
bash scripts/update-codex-skills.sh

Windows users can run:

powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\update-codex-skills.ps1
