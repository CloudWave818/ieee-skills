# Architecture Diagram

Check:

1. inputs and outputs are clear.
2. module names match the method section.
3. arrows show data flow unambiguously.
4. tensor/signal dimensions are included when helpful.
5. visual hierarchy emphasizes the proposed components.
6. the diagram is not overloaded with implementation details.

For learning-based control, reinforcement learning, or neural-network framework diagrams, also check:

1. system boundary, environment, state, action, reward/cost, and constraints are explicit.
2. actor, critic, encoder, replay buffer, update rule, or target network blocks match the method section.
3. training path and deployment/inference path are visually distinguishable.
4. the diagram does not hide engineering constraints behind a generic neural-network block.
5. caption states the application scenario and what the framework proves.
