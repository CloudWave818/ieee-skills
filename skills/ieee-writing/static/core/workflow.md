# Workflow

1. Extract the paper kernel:
   - object
   - target condition
   - engineering harm
   - prior-method limitation
   - proposed mechanism
   - evidence and metrics
2. Select the venue, section, language, and domain fragments from `manifest.yaml`.
3. Draft the one-sentence argument before drafting prose.
4. Build the section around the selected section fragment.
5. Insert quantitative results only when provided by the user.
6. Run a reviewer-risk pass against scope, novelty, validity, data, clarity, compliance, and advancement.
7. Return the draft plus compact missing-evidence notes.

Do not turn missing evidence into confident claims.
